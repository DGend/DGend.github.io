Supervised Learning

#3 원본 노드

개요

지도 학습은 입력(특성)과 정답(레이블)이 짝지어진 데이터로부터, 새로운 입력에 대해서도 올바른 출력을 내놓는 함수를 추론하는 머신러닝 방법론이다. 학습의 목표는 단순히 훈련 데이터를 암기하는 것이 아니라, 훈련에 쓰이지 않은 보이지 않는 데이터에도 합리적으로 일반화하는 것이다. 지도 학습은 크게 이산적인 범주를 예측하는 분류와, 연속적인 값을 예측하는 회귀로 나뉜다. 예를 들어 선형 회귀는 설명 변수와 반응 변수 사이의 선형 관계를 추정하고, 로지스틱 회귀는 어떤 입력이 특정 클래스에 속할 확률을 모델링하여 이진 분류에 흔히 쓰인다.

지도 학습 문제를 실제로 풀려면 몇 단계를 거친다. 먼저 훈련 예시의 유형을 정하고, 함수의 실제 사용을 대표할 수 있는 훈련 데이터를 모은다. 이어서 입력 객체를 특성 벡터로 표현하는 방식을 정하고, 학습에 쓸 알고리즘과 모델 구조(예를 들어 서포트 벡터 머신이나 의사결정 트리)를 선택한 뒤 훈련을 진행한다. 마지막으로 훈련에 쓰지 않은 별도의 테스트 세트로 학습된 함수의 정확도를 평가한다.

알고리즘을 고를 때는 몇 가지 요소를 함께 고려해야 한다. 대표적인 것이 편향과 분산의 트레이드오프다. 모델이 너무 단순하면 데이터의 구조를 충분히 반영하지 못해 편향이 커지고, 반대로 너무 유연하면 훈련 데이터의 노이즈까지 학습해 버려 분산이 커지는 과적합이 발생한다. 이 외에도 실제 함수의 복잡도 대비 훈련 데이터의 양, 입력 특성 벡터의 차원(차원의 저주), 출력값에 섞인 노이즈의 정도, 데이터의 이질성과 중복성, 특성 간 상호작용 여부 등이 알고리즘 선택에 영향을 준다.

지도 학습 알고리즘은 일반적으로 손실 함수를 정의하고, 이를 훈련 데이터 위에서 최소화하는 함수를 찾는 방식으로 동작한다. 이를 경험적 위험 최소화라 부르며, 여기에 모델 복잡도에 대한 페널티를 더해 편향과 분산의 균형을 제어하는 접근을 구조적 위험 최소화라 한다. 또한 학습 방식은 서로 다른 출력을 구별하는 데 집중하는 판별적 모델과, 데이터가 어떻게 생성되는지를 확률적으로 모델링하는 생성적 모델로도 구분할 수 있다.

표준적인 지도 학습을 확장한 변형들도 있다. 훈련 데이터 중 일부만 레이블이 있는 준지도 학습, 학습 알고리즘이 스스로 어떤 데이터에 레이블을 붙일지 질의하는 능동 학습, 단일 값이 아니라 구문 분석 트리처럼 구조화된 출력을 예측하는 구조적 예측, 개별 항목의 값보다 항목 간 상대적 순서를 학습하는 랭킹 학습 등이 대표적이다.

지도 학습은 충분한 양질의 레이블 데이터가 있을 때 높은 예측 정확도를 얻을 수 있고, 입력과 출력의 매핑이라는 목표가 명확해 성능 평가와 최적화가 비교적 쉬우며, 분류와 회귀를 비롯한 다양한 문제에 두루 적용할 수 있다는 장점이 있다. 반면 크고 다양한 레이블 데이터를 구축하는 데 많은 비용과 시간이 들고, 테스트 데이터의 분포가 훈련 데이터와 크게 다르면 성능이 급격히 나빠지며, 사람이 직접 레이블을 다는 과정에서 편향이 모델에 그대로 반영될 수 있다는 한계도 함께 지닌다.
