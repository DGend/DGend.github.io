#21 원본 노드

개요

메타 러닝은 "학습하는 법을 배우는" 능력을 다루는 머신러닝의 한 분야다. 기존의 지도학습은 하나의 고정된 대규모 데이터셋으로 단일 작업을 풀도록 모델을 훈련하지만, 메타 러닝은 서로 관련된 여러 작업(각기 훨씬 작은 자체 데이터셋을 가진)의 집합을 다룬다. 개별 작업들의 학습 과정에서 공통되는 일반 정보를 추출함으로써, 새로운 작업에 대한 적응력을 높이는 것이 목표다. 이는 인간이 과거 경험을 바탕으로 단 몇 개의 예시만으로 새로운 일을 빠르게 익히는 방식과 닮아 있다.

메타 러닝이 필요한 이유는 학습 알고리즘마다 데이터에 대한 가정, 즉 귀납적 편향이 다르기 때문이다. 어떤 알고리즘은 특정 도메인에서는 매우 잘 작동하지만 다른 도메인에서는 그렇지 못하다. 문제의 속성과 알고리즘의 성능, 그리고 과거 데이터에서 파생된 패턴 같은 메타데이터를 활용하면, 주어진 문제에 맞는 학습 알고리즘을 선택하거나 변형하거나 조합할 수 있다. 이 아이디어의 원형은 Jurgen Schmidhuber(1987)와 Yoshua Bengio 등(1991)의 초기 연구로 거슬러 올라가며, 유전적 진화가 각 개체의 뇌에서 실행되는 학습 절차 자체를 유전자에 인코딩해 학습한다는 비유에서 영감을 얻었다.

일반적인 메타 러닝 작업 흐름은 메타 훈련과 메타 테스트라는 두 단계로 이루어진다. 메타 훈련 단계에서는 각기 고유한 특성을 가진 다양한 작업들에 모델(학습자)을 노출시켜, 작업들 사이에 공유되는 지식이나 공통 패턴을 학습하고, 적은 예시만으로 매개변수를 새로운 작업에 맞게 빠르게 조정하는 능력을 기른다. 메타 테스트 단계에서는 훈련 중 본 적 없는 완전히 새로운 작업을 제시하고, 소량의 데이터만으로(few-shot) 모델을 적응시킨 뒤 얼마나 빠르고 잘 일반화하는지를 평가한다. 이 과정에서 메타 손실의 그래디언트를 원래 모델 가중치까지 역전파하는데, 이는 2차 도함수를 포함해 계산 비용이 크다.

메타 러닝의 접근법은 크게 세 갈래로 나뉜다. 모델 기반(model-based) 접근은 메모리 증강 신경망이나 Meta Networks처럼, 모델 자체의 구조나 외부 메모리를 통해 소수의 학습 단계만으로 빠르게 매개변수를 갱신한다. 메트릭 기반(metric-based) 접근은 샴 신경망, 매칭 네트워크, 관계 네트워크, 프로토타입 네트워크처럼 입력 간의 유사성이나 거리를 측정하는 메트릭 공간을 학습해, 새 클래스를 최근접 이웃 방식으로 분류한다. 최적화 기반(optimization-based) 접근은 LSTM 메타 학습기나 MAML, Reptile처럼 적은 예시로도 빠르게 학습이 수렴하도록 최적화 알고리즘이나 초기 매개변수 자체를 조정한다. 이 중 MAML은 경사 하강으로 학습하는 어떤 모델에도 적용 가능한 일반적 알고리즘으로, 몇 번의 그래디언트 단계만으로 새로운 작업에 적응할 수 있는 좋은 초기 가중치를 찾는 것을 목표로 한다.

메타 러닝은 few-shot 이미지 분류부터 로보틱스, 강화학습, 자연어처리에 이르기까지 다양한 도메인에서 활용되어 왔다. 다만 2020년대 중반 현재 트랜스포머 기반 접근이 부상하면서 메타 러닝이 앞으로 얼마나 큰 효과를 발휘할지는 여전히 불확실하다. 그럼에도 제한된 데이터에서 빠르게 적응해야 하는 문제 상황에서는 여전히 상당한 잠재력을 지니고 있으며, 이 장에서는 그 대표적인 알고리즘들을 개괄적으로 소개한다.
