#7 원본 노드 NLP / LLM

개요

신경망 이전 시대의 NLP는 규칙 기반 접근과 통계적 접근이 공존하며 발전했다. 비지도 학습 기법인 잠재 디리클레 할당(LDA)은 문서를 여러 주제의 혼합으로, 각 주제를 단어 분포로 보는 베이지안 확률 모델로, 디리클레 분포와 깁스 샘플링 같은 베이지안 추론을 통해 문서 집합에 숨어 있는 잠재 주제 구조를 추론한다. 최대 엔트로피 모델은 품사 태깅, 문장 경계 탐지, 전치사구 결합, 개체명 인식 등에서 여러 이질적인 특징(feature)을 하나의 로그 선형 모델로 결합하는 방법으로, 주어진 제약 조건을 만족하는 모델 가운데 엔트로피가 가장 큰(즉 가장 정보가 적은, 편향되지 않은) 모델을 선택한다는 원리에 기반한다. 이는 나이브 베이즈와 달리 자질 간의 상관관계를 무시하지 않는다는 장점이 있다.

메모리 기반 언어 처리(인스턴스 기반 학습)는 데이터로부터 명시적인 규칙을 추출하기보다, 새로운 사례를 메모리에 저장된 과거 사례들과 비교해 가장 유사한 이웃(k-최근접 이웃 등)으로부터 유추적으로 답을 이끌어내는 방식이다. 노이즈나 예외적 사례까지 그대로 저장해 둔다는 점에서 "게으른(lazy) 학습"이라 불린다. 문법 유도(grammar induction, 비지도 구문 분석)는 사람이 정한 규칙 없이 관찰된 문장들로부터 형식 문법(재작성 규칙이나 유한 상태 오토마타 등)을 스스로 학습해 구문 트리를 생성하는 문제로, 지도 학습 구문 분석기가 소수 언어와 장르에 제한된다는 한계를 보완하려는 시도였지만 수십 년의 연구에도 성능이 만족스럽지 않은 어려운 과제로 남아 있었다.

조건부 무작위장(CRF)과 은닉 마르코프 모델(HMM)은 순차적 레이블링 문제의 대표적 통계 기법이다. CRF는 이웃한 레이블 사이의 종속성을 그래프 구조로 명시적으로 모델링하며, 특히 자연어 처리에서는 각 예측이 바로 옆 이웃에만 의존하는 선형 체인 CRF가 널리 쓰였고, 품사 태깅이나 개체명 인식처럼 인접 토큰의 레이블이 서로 영향을 주는 작업에 효과적이었다. HMM은 마르코프 모델에 직접 관찰되지 않는 은닉 상태 개념을 도입한 것으로, 품사 태깅에서는 단어가 관찰된 상태, 품사 태그가 은닉 상태에 해당하며, 전이 확률과 방출 확률을 이용해 비터비 알고리즘으로 가장 가능성 높은 태그 시퀀스를 찾는다.

토큰화는 원문 텍스트를 기계가 처리할 수 있는 최소 단위(토큰)로 분해하는, 거의 모든 NLP 파이프라인의 첫 단계다. 단어 단위, 문장 단위, 하위 단어 단위, 문자 단위 등 세분성에 따라 여러 방식이 있는데, 단어 토큰화는 직관적이지만 어휘 외(OOV) 단어와 어휘 크기 폭증 문제를 안고 있고, 문자 토큰화는 어휘 문제는 해결하지만 시퀀스 길이가 급격히 길어지며 의미 있는 단위를 학습하기 어렵다는 단점이 있다. 이 절충안으로 등장한 하위 단어 토큰화는 접사 등을 분리해 단어를 더 작은 의미 단위로 나눔으로써 OOV 문제와 어휘 크기 문제를 동시에 완화한다. 그 밖에도 의미 중의성, 언어와 문자 체계의 차이(중국어, 일본어처럼 단어 사이에 공백이 없는 경우), 구두점 처리, 비정형·구어체 텍스트 처리 등이 토큰화의 대표적 난점으로 꼽힌다.

규칙 기반 NLP와 통계적 NLP는 신경망 이전 시대를 지배한 두 축이다. 규칙 기반 모델은 언어 전문가가 하향식으로 작성한 IF-THEN 형태의 규칙에 따라 구문 분석, 태깅, 정보 추출 등을 수행하며, 투명하고 해석 가능하고 대량의 데이터가 필요 없다는 장점이 있으나, 규칙의 확장과 유지보수가 어렵고 언어의 모호성과 창의적 변형에 취약하다는 한계가 있었다. 1990년대 이후 이러한 한계를 극복하기 위해 통계적 방법이 도입되었는데, 이는 대량의 코퍼스에서 관찰되는 패턴과 확률 구조를 귀납적으로 학습하는 접근으로, 언어 모델링(선행 단어들로부터 다음 단어의 확률을 예측), 나이브 베이즈 분류, 단어 빈도 기반의 TF-IDF, 상관·회귀 분석, 군집화와 차원 축소를 이용한 토픽 모델링 등이 대표적이다. 다만 통계적 방법 역시 데이터 희소성과 문맥 포착의 한계라는 어려움을 겪었다.

마지막으로 NLP와 인공지능(AI)의 관계를 보면, NLP는 AI라는 더 큰 범주 안에서 컴퓨터와 인간 언어 사이의 상호작용을 다루는 하위 분야로 자리매김한다. 머신 러닝과 딥 러닝 같은 AI 기술은 감정 분석, 언어 번역, 음성 인식 등 다양한 NLP 작업의 모델을 학습시키는 기반이 되고, 반대로 NLP는 AI 시스템이 비정형 텍스트 데이터를 이해하고 처리하도록 함으로써 챗봇, 가상 비서, 정보 검색 시스템 같은 응용을 가능하게 한다. 즉 언어 이해라는 능력을 매개로 NLP와 AI, 머신 러닝은 서로를 강화하며 발전해 왔고, 이러한 상호작용이 궁극적으로는 보다 인간에 가까운 기계 지능을 향한 흐름의 한 축을 이룬다.
