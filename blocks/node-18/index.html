#18 원본 노드 NLP / LLM

개요

사전학습 언어모델(PTM)과 거대 언어모델(LLM)의 경계는 명확하지 않지만, 대체로 파라미터 수가 10억 개를 넘고 사전학습만으로도 프롬프트 조정을 통해 다양한 작업을 수행할 수 있는 모델을 LLM으로 구분한다. LLM은 PTM에서 다루는 개념을 그대로 이어받는 상위 개념이며, 여기에 대규모화에 따른 엔지니어링 요소가 추가된다.

언어모델 학습은 크게 사전학습과 미세조정 두 단계로 이루어진다. 사전학습은 방대한 비정형 텍스트 코퍼스에서 자기 지도 방식으로 일반적인 언어 표현을 학습하는 과정으로, 막대한 연산 자원이 필요하다. 미세조정은 이렇게 얻은 사전학습 모델을 감성 분석, 질의응답, 요약 등 특정 작업에 맞는 소규모 데이터셋으로 추가 학습시켜 처음부터 학습하는 것보다 훨씬 적은 비용으로 과제에 적응시키는 과정이다.

LLM은 일반적인 언어 생성과 분류 등 다양한 자연어 처리 작업을 수행하는 계산 모델로, 자기 지도 및 준지도 학습을 통해 방대한 텍스트에서 통계적 관계를 학습한다. 입력 텍스트를 받아 다음 토큰을 반복적으로 예측하는 방식으로 텍스트를 생성하며, 2017년 제안된 트랜스포머 아키텍처, 그중에서도 주로 디코더 전용 구조를 기반으로 한다. 2020년 이전에는 특정 작업에 모델을 적용하는 주된 방법이 미세조정이었으나, GPT-3처럼 규모가 커진 모델은 입력 프롬프트를 설계하는 프롬프트 엔지니어링만으로도 유사한 성능을 낼 수 있음을 보여주었다. 다만 이런 모델은 인간 언어 코퍼스에 담긴 구문, 의미, 지식을 학습하는 동시에 그 데이터에 내재된 부정확성과 편향도 함께 물려받는다.

대표적인 LLM으로는 OpenAI의 GPT 계열, Google의 Gemini, Meta의 LLaMA, Anthropic의 Claude, Mistral AI의 모델 등이 있다. 이들은 모두 딥러닝 기법으로 방대한 텍스트 데이터를 학습한 고도화된 언어모델이며, 단순히 단어 시퀀스에 확률을 부여하던 초기의 n-gram 모델과 달리 수백만에서 수십억에 이르는 파라미터를 갖는다. 텍스트 생성뿐 아니라 번역, 요약, 코드 오류 탐지 등 폭넓은 작업에 활용된다.

LLM의 두드러진 특징 중 하나는 창발적 능력(emergent ability)이다. 이는 소규모 모델의 성능을 외삽해서는 예측할 수 없다가, 모델 규모가 특정 임계점을 넘는 순간 마치 상전이처럼 갑자기 나타나는 능력을 가리킨다. 산술 연산, 질의응답, 문단 요약처럼 별도의 설계 없이 자연어를 대규모로 학습하는 것만으로 생겨나는 능력이 대표적이다.
