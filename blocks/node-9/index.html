#9 원본 노드

개요

이미지 분류는 지배적인 객체나 이미지에 존재하는 특성을 기반으로 전체 이미지를 식별하고, 미리 정의된 범주 중 하나의 레이블을 지정하는 작업이다. 예를 들어 고양이, 개, 토끼가 섞인 이미지 집합이 주어지면, 분류 모델은 각 이미지를 서로 구별되는 범주로 나눈다. 컴퓨터 비전과 머신러닝에서 가장 기본이 되는 과제이며, 픽셀이나 벡터에 적용된 규칙에 따라 이미지 내용을 인식하고 분류하는 것을 목표로 한다.

분류의 핵심 목적은 이미지를 구성하는 각 픽셀을 여러 사전 정의된 범주 중 하나에 할당하는 데 있다. 보통은 다중 스펙트럼 데이터를 활용해 데이터 내의 스펙트럼 패턴에서 분류 근거를 확립하며, 이미지에 존재하는 특성을 식별해 고유한 색상이나 명암 값으로 표현함으로써 실제 대상물에 대응시키는 것을 지향한다.

객체 간의 차이를 구별하는 일은 본질적으로 복잡한 작업이기 때문에, 이미지 분류는 디지털 이미지 분석과 컴퓨터 비전 분야의 초석으로 여겨진다. 방대한 양의 이미지를 사람이 직접 검사하고 분류하는 것은 현실적으로 매우 힘든 일이므로, 이를 자동화하는 컴퓨터 비전 기술의 가치는 매우 크다.

대표적인 접근인 감독 분류는 사용자가 이미지에서 특정 클래스를 대표하는 표본 픽셀을 직접 선택하는 원리로 동작한다. 이렇게 선택된 훈련 영역(training site)은 이미지 내 나머지 픽셀을 분류하는 기준점 역할을 하며, 사용자는 훈련 영역의 스펙트럼 속성에 따라 픽셀을 묶는 유사성 임계값과 분류할 클래스의 수를 함께 정한다. 각 클래스가 통계적으로 특성화되고 나면, 모델은 각 픽셀의 반사율 등을 분석해 가장 유사한 특성을 찾아 최종적으로 이미지를 분류한다.
