Generative AI

#17 원본 노드 Generative / Multi-Modal

개요

생성 모델은 주어진 데이터 집합의 기본 패턴이나 분포를 학습해 그와 유사한 새로운 데이터를 만들어내는 머신러닝 모델이다. 데이터가 서로 다른 범주 사이의 경계를 학습해 분류하는 판별 모델과 달리, 생성 모델은 데이터 자체가 어떻게 만들어지는지를 이해하려 한다. 예를 들어 고양이와 개 사진을 학습한 생성 모델은 각 동물이 왜 그렇게 보이는지를 포착해 새로운 고양이나 개 이미지를 만들어낼 수 있다. 생성형 AI(GenAI)는 이러한 생성 모델을 활용해 프롬프트에 응답하는 형태로 텍스트, 이미지, 비디오 등 다양한 콘텐츠를 만드는 인공지능을 가리키며, 2010년대 중반 GAN의 등장과 2020년대 초 트랜스포머 기반 대규모 언어 모델의 발전을 거치며 대중화되었다.

생성형 AI의 학습 과정은 대체로 다음 단계를 따른다. 먼저 생성하려는 종류의 데이터를 대량으로 수집하고, 노이즈 제거와 정규화, 토큰화 같은 전처리를 거친다. 이렇게 준비된 데이터를 신경망 아키텍처에 노출시켜 데이터 내부의 패턴과 상관관계를 학습시킨다. 학습이 끝나면 모델은 무작위 노이즈나 프롬프트를 입력받아 학습된 분포에서 새로운 샘플을 생성하고, BLEU나 FID 같은 지표와 주관적 평가로 결과물의 품질을 검증한 뒤 미세조정을 반복해 성능을 개선한다.

대표적인 초기 아키텍처인 변이 오토인코더(VAE)는 인코더와 디코더로 구성된다. 인코더는 입력 데이터를 하나의 고정값이 아니라 잠재 공간 위의 확률 분포로 매핑하고, 디코더는 이 잠재 공간에서 샘플링한 점을 원래 데이터 공간으로 복원한다. 입력을 단일 지점이 아닌 분포에 대응시킴으로써 잠재 공간이 매끄럽게 연속되어, 그 사이를 보간하면 원본과 비슷하면서도 조금씩 다른 새로운 데이터를 만들어낼 수 있다. VAE는 재구성 손실과 KL 발산이라는 두 가지 목표를 함께 최적화하며 학습된다.

생성적 적대 신경망(GAN)은 2014년 Ian Goodfellow가 제안한 구조로, 생성자와 판별자라는 두 신경망이 제로섬 게임 형태로 경쟁하며 학습한다. 생성자는 무작위 노이즈로부터 실제와 구별되지 않는 데이터를 만들어내려 하고, 판별자는 진짜 데이터와 생성된 가짜 데이터를 구별하려 한다. 이 경쟁이 반복되면서 두 네트워크는 함께 발전하며, 판별자가 더 이상 진위를 가려내지 못하는 지점까지 생성자의 출력 품질이 높아진다. 일반적으로 GAN은 VAE보다 더 선명하고 사실적인 결과를 만들어내지만 학습이 불안정하고 느린 반면, VAE는 학습이 안정적이고 잠재 공간을 해석하고 조작하기 쉽다는 장점이 있다.

이후 확산 모델과 트랜스포머 기반 아키텍처가 등장하며 생성형 AI는 한층 더 발전했다. 확산 모델은 데이터에 점진적으로 노이즈를 더하는 순방향 과정과 그 노이즈를 단계적으로 제거해 데이터를 복원하는 역방향 과정을 학습해 고품질 이미지, 비디오 등을 생성하며 DALL-E 2, Stable Diffusion, Sora 같은 서비스의 기반이 되었다. 한편 대규모 언어 모델(LLM)은 트랜스포머 구조와 어텐션 메커니즘을 이용해 방대한 텍스트에서 단어 간 연관성을 학습함으로써 문장·코드 등 다양한 콘텐츠를 생성한다. 이러한 발전은 소프트웨어 개발, 의료, 예술, 마케팅 등 여러 산업에 활용되지만, 편향된 출력이나 환각, 저작권·표절 문제 같은 윤리적 쟁점도 함께 제기되고 있다.
