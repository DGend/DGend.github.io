#8 원본 노드

개요

신경망을 다루는 자료는 대개 두 갈래로 나뉜다. 화살표로 연결된 원과 수식으로 이론을 설명하는 자료이거나, Tensorflow나 Pytorch 같은 프레임워크 함수 호출만 보여주는 자료다. 두 경우 모두 신경망이 실제로 어떻게 움직이는지는 잘 드러나지 않는다. 프레임워크가 지원하지 않는 알고리즘을 다루거나 복잡한 실제 응용을 만들려면 결국 딥러닝의 작동 원리를 numpy 수준에서 직접 구현할 수 있어야 하며, 그렇게 해야 풀어야 할 문제의 개념 자체에 접근할 수 있다.

소프트웨어 프레임워크는 제어 흐름을 프레임워크가 쥐고 사용자는 정해진 지점만 채워 넣는 추상화로, 개발 속도를 높여주는 대신 내부 동작을 가려버린다. 반면 NumPy는 다차원 배열(ndarray)과 그 위에서 동작하는 벡터화 연산을 제공하는 기초 라이브러리로, 신경망의 계산을 한 단계 낮은 층위에서 직접 다루게 해준다. 이 장은 이러한 numpy 수준의 구현을 통해 신경망의 원리를 체득하는 것을 목표로 한다.

가장 단순한 출발점은 단일 계층 모델이다. 선형 회귀, 퍼셉트론, 로지스틱 회귀는 각기 다른 이름으로 소개되지만 학습 구조의 원리는 동일하다. 선형 회귀는 입력과 출력 사이의 선형 관계를 오차 제곱합을 최소화하는 방식으로 추정하고, 퍼셉트론은 입력에 가중치를 곱해 합산한 뒤 활성화 함수로 임계값을 넘는지 판단해 이진 분류를 수행하며, 로지스틱 회귀는 시그모이드 함수로 그 출력을 확률로 해석한다. 이 세 모델의 계산 그래프 형태를 이해하면 이후 등장하는 더 복잡한 구조도 같은 원리의 확장으로 볼 수 있다.

단일 계층을 넘어서면 여러 계층과 다중 클래스를 다루는 구조, 합성곱 계층, 계산 그래프, 그리고 딥러닝에서 데이터를 표현하는 텐서 개념으로 이어진다. 계산 그래프 형태로 모델을 이해하면 순전파와 역전파가 코드 상에서 어떻게 맞물리는지 파악하기 쉬워지고, 이는 batch 단위 학습이나 gradient 초기화 같은 프레임워크의 관례적 동작을 스스로 재현하는 데도 도움이 된다.

활성화 함수는 은닉 계층에서 다음 뉴런으로 정보를 전달할지 결정하는 요소로, 시그모이드나 하이퍼볼릭 탄젠트, ReLU처럼 고정된 형태도 있고 학습 과정에서 형태 자체가 조정되는 종류도 있다. 학습이 건전하게 진행되고 과적합을 방지하며 정확도와 계산 비용의 균형을 맞추도록 다양한 활성화 함수가 개발되어 왔다.

옵티마이저는 손실 함수를 최소화하는 방향으로 신경망의 가중치와 편향을 갱신하는 알고리즘이다. 안개 낀 산에서 가장 가파르게 낮아지는 방향으로 조금씩 내려가는 과정에 비유할 수 있으며, 경사 하강법과 확률적 경사 하강법, 미니배치 경사 하강법에서부터 Adam, Adagrad, RMSprop, Adadelta, Nesterov 가속 경사, Nadam에 이르기까지 저마다 다른 방식으로 이 하강 과정을 개선한다. 신경망의 손실 함수는 여러 국소 최소값을 갖는 비볼록 함수인 데다 고차원이어서 계산 비용이 크기 때문에, 어떤 옵티마이저를 선택하느냐가 모델의 학습 성패에 큰 영향을 미친다.
